# demos

Демо-сайты для бизнеса на одном домене. Каждый бизнес живёт в своём роуте:
`/hotel` — отель на Иссык-Куле. Следующие на очереди: `/clinic`, `/restaurant`, `/beauty`.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000 (список демо) и http://localhost:3000/hotel.

## Стек

- **Next.js 15** (App Router) + **React 19** + **TypeScript**
- **Tailwind CSS v4**: токены цветов и шрифтов в `src/app/globals.css`
- **Motion** (бывший Framer Motion): анимации, скролл-эффекты, drag
- **Lenis**: плавный скролл
- **React Three Fiber + three.js**: 3D-тундук на странице отеля
- **react-day-picker + date-fns**: календарь брони
- **sonner**: уведомления
- **react-icons**: только логотипы мессенджеров; остальные иконки свои (`src/components/icons`)
- Шрифты: Unbounded (заголовки) и Onest (текст) через `next/font`, с кириллицей

## Архитектура

```
src/
  app/
    page.tsx              — витрина всех демо
    hotel/page.tsx        — роут /hotel (метаданные + страница)
  demos/
    registry.ts           — список демо для витрины
    hotel/
      config.ts           — ВЕСЬ контент отеля: название, контакты, номера, цены, фото
      booking-context.tsx — выбранный номер и прокрутка к брони
      hotel-page.tsx      — сборка секций
      components/         — секции лендинга
  components/
    icons/                — авторский набор иконок
    providers/            — плавный скролл, настройки анимаций
  lib/                    — ссылки на мессенджеры, загрузчик картинок, утилиты
```

**Сделать сайт под реального клиента:** скопировать `src/demos/hotel` и поменять `config.ts`
(название, номер WhatsApp, Telegram, Instagram, номера и фото). Разметку трогать не нужно.

**Добавить новый бизнес:** создать `src/demos/<slug>/`, роут `src/app/<slug>/page.tsx`
и запись в `src/demos/registry.ts`.

## Как работает бронь

Гость выбирает даты, номер и количество гостей. Сайт считает ночи и предварительную сумму
и собирает текст заявки:
- **WhatsApp** — открывается чат с уже заполненным сообщением;
- **Telegram** — текст копируется в буфер, открывается чат отеля.

Сервер и база не нужны: заявка сразу приходит администратору в мессенджер.

## Деплой

Проще всего на Vercel: залить репозиторий на GitHub → vercel.com → New Project → импорт `demos`.
Свой домен подключается в настройках проекта, все демо будут на нём: `domain.kg/hotel` и т. д.

## Фото

Все фото с Unsplash (бесплатная лицензия), грузятся через `src/lib/image-loader.ts`
сразу нужного размера. Для реального клиента замените ссылки в `config.ts` на его фото
(можно положить в `public/` и указать путь `/photo.jpg`).
